# 评分与提问量表

仅在需要评估、规划学习路线或生成问题时读取本文件。评分是带证据的辅助判断，不是事实认证。

## 评分维度

每项按 0–10 分评分，并给出一条来自材料结构、段落、示例或论证的依据，以及高/中/低置信说明。

| 维度 | 高分信号 | 低分信号 |
| --- | --- | --- |
| 可读性 | 标题层次清楚；段落聚焦；术语解释充分；逻辑衔接自然 | 结构混乱；跳步；术语堆叠；重复或含混 |
| 可学习性 | 前置知识明确；从基础到应用；有示例、练习或检验点 | 假定读者已知过多；只有结论；缺少例子或步骤 |
| 准确与可信度 | 论据、来源、限制和适用条件清晰 | 无依据的断言；绝对化措辞；忽略反例或时效性 |
| 信息密度 | 每节推动一个有效观点；重复少；细节服务于结论 | 套话、反复表达、无关铺垫或堆砌细节 |
| 可应用性 | 给出决策规则、可执行步骤、场景或可迁移方法 | 内容只能记住，难以判断何时或如何使用 |

## 按材料类型调整

- **技术教程**：重点检查前置条件、步骤可复现性、代码/示例解释、失败情形与验证方式。
- **概念文章**：重点检查定义、概念关系、类比是否准确、是否能区分相近概念。
- **报告**：重点检查数据/来源、方法、样本或假设、结论边界与时效性。
- **观点长文**：重点检查主张、论据链、反例、价值判断和未说明的前提。

## 学习问题选择

每轮只提出一个问题。优先从下列层级中选择当前最小必要问题：

1. **理解**：用自己的话定义概念、解释段落主张或识别例子。
2. **关系与推理**：解释因果、比较概念、找出隐含前提或预测条件变化后的结果。
3. **应用与迁移**：在一个新场景中选择方法、提出步骤、判断边界或反驳错误做法。

回答评估只使用“已掌握”“部分掌握”“需回看”。对“部分掌握”先补一个小缺口；对“需回看”给出准确的小节/段落和聚焦问题，不要重复整篇讲解。
