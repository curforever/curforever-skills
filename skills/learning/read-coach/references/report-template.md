# 学习报告模板说明

报告必须保留以下六个二级标题和顺序。使用脚本创建和更新，不要修改原文。

## 1. 30 秒结论

记录是否值得读、建议阅读深度、关键收获和主要风险或边界。

## 2. 质量评分与依据

记录五个评分维度、每项依据与置信说明。避免把分数写成事实判断。

## 3. 核心知识地图

记录 3–7 个核心概念或论点，以及它们的关系、顺序或因果。

## 4. 互动学习记录

按发生顺序简要记录问题、用户回答、掌握状态、必要反馈和下一步。

## 5. 应用练习与答案要点

记录练习、判断题或迁移任务及答案要点。若材料不适合实践，记录反例或立场辨析任务。

## 6. 最终掌握总结与下一步

记录用户自己的总结、补充纠偏、仍需回看的内容和可选下一步。
