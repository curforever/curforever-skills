# 本地 AI 资讯延伸问答整理

用户要求集中整理某期日报问答时，读取 [整理要求](references/prompt.md)。仅处理用户指定的日期与已有日稿；目录沿用该日稿或同级 `../ai-news-local/SKILL.md` 的输出配置，不扫描其他项目。

1. 优先用户指定日期/文件，否则结合当前会话新闻、批注和现有日稿判定。无法唯一确定时澄清，不默认写入今天、不新建同日副本。
2. 读取当前会话的问题、追问和回答，以及日稿已有完整问答。用户指定其他会话且工具可用时再补齐；不能假称读过不可见的内容。
3. 建立原问题/追问到成稿问答的对应，按话题合并重复内容，保留每个独立疑问。重要未答问题联网补核；未知明确说明，来源保留直接链接。
4. 修改前在临时目录保留原文件快照。只替换末尾 `## 延伸问答` 及其紧邻分割线；没有则追加。新闻正文、封面引用及已有新闻来源保持原样。
5. 按 `### Qn｜短标题` 连续编号，紧跟 `> 完整问题`，先给结论再解释。最多三级标题，主题用加粗段落，避免重复分割线或机械按聊天时间平铺。
6. 完整读回，核对新闻正文前缀未变、问题无遗漏、来源和编号正确。若用户需要 HTML，先确认同级 ai-news-local 及其 Python Markdown 依赖可用，再从该技能实际路径运行 `scripts/reading.py --source <日稿>`；不可用时保留 Markdown 并说明。

仅返回本地 Markdown 链接及有必要说明的未验证项。集中整理授权仅限对应本地问答；不包含发布、远端同步或新建自动化。
