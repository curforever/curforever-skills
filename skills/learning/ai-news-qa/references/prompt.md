# 整理要求

整理本会话围绕指定日期 AI 资讯日报的延伸问答，原位更新已有 Markdown 日稿。

- 按事件或概念关联归并，例如 A、B、C、A1、A2 应把 A、A1、A2 组织在一起。保留不同疑问的关键信息，不为了分组刻意复杂化。
- 保留有效旧问答，合并重复追问；重要未答问题补核后回答，不能把未知包装成事实。每答先给结论，再用必要事实和贴切场景说明。
- 操作/安装/Skill/提示词经验只保留与资讯有关的真实入口、前提、最短行动与完成标志。日报排版或技能维护本身的讨论不混入资讯问答。
- 问答前只放一条分割线；H2 为延伸问答，H3 为连续 Q 编号和短标题，引用块保留完整问题；来源给可点击原文链接。需要分组时用加粗主题段落。
- 保存后完整读回并核对正文、封面、原来源未变。HTML 仅在需要且依赖可用时刷新。本流程只写本地，不执行外部发布。
