# 本地 AI 资讯日报

## 调用与输出位置

- `$ai-news-local 生成今天的 AI资讯日报`：分析、会话呈现、保存本地 Markdown。
- 用户指定日期或旧稿时更新该日期唯一文件，保留已有延伸问答。不以今天日期替代无法确认的历史日期。
- 单条追问维护所讨论日期末尾的 `## 延伸问答`；集中整理时可用同级 `../ai-news-qa/SKILL.md`。
- 输出目录优先使用用户指定位置，其次使用当前项目已明确配置位置；否则使用当前项目根下的 `日报/AI资讯/`。所有产物路径均相对此目录；不写入技能目录。
- 每天唯一 `YYYY-MM-DD-AI资讯日报.md`，第一行 `# YYYY年M月D日 AI资讯日报`。时区采用用户会话时区，未另行指定时使用 Asia/Shanghai；统计日期显示 `*统计时间：YYYY-MM-DD（北京时间）*`，选题截止内部保留准确时刻。

生成或改稿前读取 [选题与来源](references/sources.md) 和 [呈现规范](references/style.md)。本技能没有外部发布步骤，不调用企业内部工具，不创建定时任务。仅在用户另行要求自动化时使用 [自动化提示词](references/automation-prompt.md)。

## 分析与选题

1. 确认实际日期与截止，按需读取输出目录下当天及前两个自然日的日报。旧稿以其原截止为界；截止未知时不声称某条属于近 24 小时。
2. 行业资讯优先重要团队的重大变化。近 1 天前置，再选近 7 天热点。区分事件日期和报道日期；未知时间不硬归窗。
3. 与前两期按同一事件/实质变化去重。近 7 天条目的事件重复率目标不超过 20%；分母为零不计算。说明新增进展，不为比例补低价值内容。
4. 实践工具优先低门槛、适用于用户当前平台、同事可复用、能较快见效的工具、Skill、Agent 与工作流。兼顾研发、性能、排障、知识复用、协作和办公；不将私人项目内容写入公共正文。
5. 实践、方法与跨界案例允许早于 7 天，注明原日期或“实践精选，非当日首发”。方法说明可迁移的思路，跨界说明具体应用。
6. sources.md 是候选来源池。逐条打开一手原文，核实核心事实、日期、状态、安装入口和平台；传闻、作者体验、厂商宣称须归属来源。无法联网时报告不能生成已核实当日资讯，不编造热度、链接或事实。

## 呈现与保存

固定结构：**今日导读 → 🟠 行业资讯 → 🔵 实践工具 → 🟣 方法启发 → 🟢 跨界发现**。正文篇幅倾向约 30%/50%/10%/10%，不设硬条数。

会话完整展示标准 Markdown 日报正文，不重贴全部历史问答。每条给直接原文链接；实践条目附当前已核实的安装/访问入口、前提和完成标志，不执行推荐工具的安装。

使用当前可用 Python 运行本目录下的辅助脚本（`<skill-dir>` 是本 SKILL.md 所在目录，所有路径按当前 shell 引用）：

```text
python "<skill-dir>/scripts/article.py" save --draft "<临时正文.md>" --target "<输出目录>/YYYY-MM-DD-AI资讯日报.md"
```

脚本校验标题日期、章节顺序、导读与正文连续编号，保留旧问答并原子保存。封面为可选：若有，使用真实存在的 `_assets/YYYY-MM-DD-AI资讯横幅.png`，不可伪造图片路径。可在用户需要时使用 assets 中的提示词和参考图。

Markdown 是主要交付；可选 HTML 阅读页通过下面命令生成，需要当前 Python 环境已安装 `Markdown` 包。依赖缺失时保留 Markdown 并明确报告，不宣称 HTML 已生成、不静默安装。

```text
python "<skill-dir>/scripts/reading.py" --source "<目标日稿>"
```

重跑前检查现有稿，保存后读回关键正文、来源、问答及图片。已有稿不写重复副本，问答保持其历史日期。正文与 HTML 更新的验收分别报告。
