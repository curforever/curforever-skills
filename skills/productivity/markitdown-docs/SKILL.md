# MarkItDown 文档转换

先确认用户指定的输入与输出。使用当前环境中实际可用的 Microsoft MarkItDown，不依赖原作者的专用虚拟环境路径。

## 环境与调用

先检查 `markitdown --help`；未找到命令时检查 `python -m markitdown --help`。使用同一已确认的 Python 环境执行后续命令。仅找到 Python 不代表转换器或格式可选依赖已安装；缺少时报告具体依赖，不静默升级或重装。

```text
markitdown "输入文件.docx" -o "输出文件.md"
python -m markitdown "输入文件.docx" -o "输出文件.md"
```

命令按当前 shell 引用路径。输入与输出路径由用户提供或从输入文件解析；不要把示例路径当作实际安装位置。用户授权安装时，再查当前官方说明，选择格式所需的可选依赖。

## 转换与验收

1. 输入必须真实存在且可读。未指定输出时，在输入文件旁生成同名 `.md`；已有文件时改用新文件名，或按明确覆盖授权处理。
2. 执行转换并检查退出状态，确认结果非空。抽查标题、正文、表格、关键数值，记录遗漏。
3. 批量时只枚举用户指定范围，逐个转换，分别报告成功和失败。
4. 返回可点击的输出绝对路径及实际限制。Markdown 面向文本分析，不能当作原排版的无损副本。

扫描 PDF、图片文字可能需要 OCR；基础安装不意味着 OCR 可用。不执行文档宏或代码，不自动将敏感文件发送到云服务。
