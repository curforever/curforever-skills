# Personal Agent Skills

这是个人维护的 Agent Skills 集合。每个 skill 位于 `skills/<领域>/<skill-name>/`，并保持独立、可测试、可按子目录发布。

## Skills

| Skill | 用途 | 状态 |
| --- | --- | --- |
| `read-coach` | 评估学习材料质量，并通过自适应问答帮助用户掌握核心内容 | 开发中 |

## 约定

- 每个 skill 必须含有 `SKILL.md`，并将可复用脚本、参考资料和测试留在该 skill 内。
- 不将真实文章、对话学习记录或生成的 `*.read-coach.md` 报告提交到此仓库。
- 本仓库采用 [MIT License](LICENSE)。公开发布前补充各 skill 的安装示例。
