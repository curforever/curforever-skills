# README 信息架构设计

日期：2026-08-23  
状态：已获用户批准，待实施

## 目标

将仓库首页从单一 `read-coach` 的介绍页调整为整个技能集合的发现页。读者应在首屏快速理解仓库用途，并能按使用场景找到和安装任一 skill。

## 页面结构

1. 标题、中文简介和一句英文简介。
2. `## Skills`：作为第一个主要章节，按稳定顺序分为开发与工程、学习与知识、生产力、项目管理、沟通与写作。每组使用 `Skill / 说明 / 安装路径` 三列表格。
3. `## 安装`：用一个通用命令模板说明 `gh skill install`，并给出 Codex、Claude Code、Cursor、GitHub Copilot 的最小替换说明。安装示例不绑定任何具体 skill。
4. `## 隐私与安全`：说明安装前审阅内容、不要提交真实资料或凭据。
5. `## 开发与贡献` 与 `## License`：保留并精简现有内容。

删除 `快速开始：Read Coach`、`Read Coach 能做什么`、`使用示例` 和 `学习报告` 四个仅适用于单一 skill 的章节。`read-coach` 的专属说明仍在其 skill 目录中。

## 分类与排序

分类的显示顺序固定为：

1. 开发与工程（`development`）
2. 学习与知识（`learning`）
3. 生产力（`productivity`）
4. 项目管理（`project-management`）
5. 沟通与写作（`communication`、`writing`）

每个分组内按 skill 名称排序。新增未知分类时，同步过程必须阻止发布，直到提供公开显示名称和排序位置。

## Skill Manager 变更

- 技能映射增加分类显示名称和固定顺序信息。
- 同步脚本以分组表格重建 README 的 `Skills` 段，而非生成单一的字母排序表。
- 工作流要求：每次新增、重新归类或更新公开摘要时，必须运行预演并检查 README 的分组、链接和安装路径。

## 验证

- README 不再出现 `Read Coach` 专属首页章节或单一默认安装路径。
- 所有映射的 skill 恰好出现一次，链接和安装路径与发布目录一致。
- 分类顺序、组内排序和通用安装命令稳定且正确。
- `skill-manager` 的默认预演不会产生目录重复或 README 无关改动。
